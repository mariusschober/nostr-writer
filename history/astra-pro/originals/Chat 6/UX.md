# UX/UI contract — writing first, evidence second

This is an implementation specification, not a claimed rendered prototype. The visual direction is deliberately chosen: the restrained source-first rhythm of iA Writer, normal macOS document conventions, and optional discipline rather than a permanently locked product. No web-style dashboard, authenticity heatmap by default, marketing homepage or invented “AI probability” screen.

## Window and typography

Default new window 1120×760pt, minimum 760×520pt. A native unified toolbar holds sidebar toggle; document title/location proxy; flexible space; Focus; Preview/Export; Publish. Icons have accessible names and tooltips; Publish is a labeled button, not an unexplained glyph. Use standard macOS accent/focus rings, system semantic text/background/separator colours and native sheets. Avoid custom chrome mimicking a specific OS generation. Default sidebar width 232pt; inspector 288pt; both resizable/collapsible. Writing region stays centred with a 72-character preferred measure, ≥28pt side margins at minimum width, 32pt top breathing room. Font preferences offer System Mono, System Sans and Georgia; default System Mono 18pt, line spacing approximately 1.5. Sizes 13–32pt, measure 50–100 characters; zoom changes presentation, never bytes.

The source editor is plain Markdown with restrained syntax colouring and real caret/selection. Headings visually emphasize structure without hiding editable delimiters. Inline link/image syntax is not silently rendered away. There are no floating formatting panels following each selection. The status strip has word count, durable-save state and a small Writing History/Proof control. Status never changes line layout or steals focus.

Sentence/paragraph focus dims other text to an accessible but distinguishable secondary treatment; it does not hide selected text, find matches, IME composition or errors. Typewriter scroll keeps the caret near 45% viewport height only during actual editing; find, mouse scrolling and accessibility navigation remain under user control. Reduce Motion disables animated scrolling/fades. Separate paginated Preview uses the export renderer rather than an approximate HTML representation.

## Screen/flow inventory and exact behaviour

**U01 — first launch.** Open an empty native document, not Nostr setup. One short nonmodal-onboarding sheet explains optional recording of typing/revisions/deleted text on this Mac. Actions: Start Writing with Recording; Write Without Recording; Learn About Proof (local help). No microphone/network/AX permissions are requested. Empty editor placeholder: “Write what you think.” It vanishes on first text and is not part of the document. Closing the sheet defaults recording off until explicit consent. Subsequent launch restores safe documents and caret, not an unescapable session.

**U02 — ordinary writing.** New/Open/Save/Save As/Close/Duplicate/Reveal in Finder/Print use familiar native behaviour. Opening the same file focuses its existing DocumentSession rather than opening two independent writers to it. Separate documents may have separate windows; native tabs are permitted. Library sidebar sections: Open, Recent, Pinned, Nostr Drafts (only after connection), Outbox (only when nonempty), and optional Quick Posts. A recents entry is a reference to a file, not a cloud copy owned by the app. Remove from Recents does not delete a file. Rename and Move use explicit file actions; Move to Trash requires confirmation showing the file and optional owned asset folder. Search is local filename/title/content for already user-opened/selected folders only; never scan the user's disk.

**U03 — outline and find.** Outline shows actual ATX/Setext headings parsed from the snapshot; clicking scrolls source and preserves undo. Find is Cmd-F native search; replace is explicit and attributed as a transformation (not reconstructed keystrokes). Replace All previews the match count and creates one reversible semantic edit. Search typing never enters document telemetry. There is no default regex mode; literal, case, whole-word options are sufficient. A stale parse/search result never rewrites text.

**U04 — recording/provenance inspector.** Default summary: “Writing history stays on this Mac” or “Recording off.” Show observed direct input, external/assisted wording, unsupported input and gaps as provenance categories, not statistical verdicts. Selecting a marked span shows its exact source/category and affected source range. Visual highlighting can expand to a whole grapheme for readability, but persisted scope remains exact UTF-8 scalar-aligned ranges. Buttons: Pause/Resume Recording, Mark External Source, Export Detailed Evidence, Delete Local History. Delete history gives the exact loss of future recomputation and does not claim to revoke an already exported proof. Native path/model absence reads “NOT PROVABLE — no approved Mac capture profile and model are installed.” No percentage or suggestion to manufacture edits.

**U05 — proof review.** Check Human Writing Proof is explicit and works off the immutable revision. During work show cancellable indeterminate/progress text without blocking editing; if text changes, results appear for the earlier version with “Document changed since this check.” A real valid result names whole/selected scope, fresh-composition/wording-origin, execution mode, policy/release identity, author binding if any, and whether current bytes match. Main badge can say HUMAN-WRITTEN only for a production VALID-HWP on the exact current selected claim. TEST-ONLY never becomes a production success. NOT PROVABLE explains absence/non-admission without an accusation; primary action returns to writing. Export Proof is disabled when no qualifying proof exists; Export Source/History remains available. Import Proof opens a paired source/proof review and never sets current editor text behind the user's back.

**U06 — external-source/citation annotation.** Select → Document → Mark External Source opens a small sheet with category quotation/citation/assisted/imported and required plain source description, optional URL. Show the selected text preview, scope and “This material is not claimed as freshly composed.” The annotation's movement/replacement tracks origins, not brittle stored character indexes. Removing the annotation does not erase import ancestry. New metadata never fabricates cryptographic coverage. User-authored prose around a quote can later have a selected-ranges claim under an approved release. Footnotes/quotes are readable/exportable even without HWP.

**U07 — assistance.** Context-menu spelling replacements and explicit dictation visibly mark their resulting span in the inspector, not with alarming red text. Before optional dictation, request mic/speech only when used; show a persistent listening indicator and Stop. Dictation inserts at a reserved selection anchor, never replaces the whole document. Interim hypotheses occupy only that operation's marked range; unrelated edits cancel/rebase safely, late callbacks cannot overwrite new text. On-device unavailable/denied yields a clear error, never silent server fallback. Automatic/generative OS changes unavailable to the capture contract must declare a gap/unsupported origin. Normal typing and all accessibility navigation remain usable.

**U08 — storage states.** Status values: Unsaved, Saving…, Saved on this Mac / Saved to [folder], Save failed, External changes need review. Do not display Cloud Synced merely because a local save completed. Provider placeholders show Open/Download progress with cancellation and retain the prior document. Conflict sheet has local/external timestamps as informational only, a comparison, Keep Both (default), Keep Local and Open External Copy; each explicitly preserves the losing version in recovery first. No silent last-writer-wins merge of provenance. If a Keychain/history store is inaccessible, keep text editable and state recording unavailable; never create a replacement identity/key that strands history.

**U09 — Preview/Export.** Preview occupies the same document window in a separate read-only mode with Back to Writing, format/template/paper options and Export. Editorial and Manuscript presets are fully specified in EXPORT.md. Show actual paginated PDF preview and its page count, title/footer settings, missing-image/font warnings, source revision and cancellation. DOCX exports explain that pagination can differ in Word/Pages. Export defaults to the last explicit directory; never overwrite source.md or private history. An HWP companion is offered only for an actually valid matching source proof, clearly labelled “Proof of source Markdown, not of PDF/DOCX layout.” Print uses the preview PDF. Export failure retains the editor and temporary file is cleaned.

**U10 — Nostr setup.** Invoked by Publish/Settings, never forced at launch. Options Generate Identity, Import nsec/hex, Add Read-only npub. Explain public actions and secret backup; show derived npub before confirmation. Save key in Keychain; absent, locked, denied and corrupt are distinct. A read-only identity cannot expose Publish/Decrypt as working actions. Connection sheet has separate public write and private draft relays, validates URL changes before use, and requests confirmation before enabling remote drafts. No automatic purchase, remote signing permission or publication.

**U11 — long-form publish.** First action opens a compact review sheet with title, optional summary/topics/HTTPS cover URL, destination relay set, exact revision, public disclosure notice and proof state. Primary Publish signs/enqueues that snapshot once. After the user explicitly enables one-click publication for this document+identity+relay set, the toolbar button publishes directly; its adjacent menu opens Review/Change Destinations. Changing identity/destination/publicness resets consent. Editing an already published article says Publish Revision. On acceptance show “Accepted by 1 of 3 relays” and Copy Article Link / Copy Exact Version Link. Keep writing; never clear the long document. Pending offline and all-failed statuses point to Outbox. Do not claim a relay receipt is permanent storage or read confirmation.

**U12 — Outbox and Quick Post.** Outbox rows show immutable revision, identity, state and per-relay status; Retry sends the same signed bytes/id. Cancel only prevents unsent/future attempts, not retracts accepted events. Remove local item does not retract publication. Quick Post opens an optional menu-bar/global-hotkey panel retaining NostrShot's speed: type → Cmd-Return → panel hides only after local durable enqueue. If enqueue/key access fails, keep panel text. Network failure creates an Outbox notice, never steals focus or concatenates failed text into a different draft. Quick Post has separate draft state and can convert to a retained long document without pretending its prefilled words are newly typed.

**U13 — remote drafts.** Local save is always first. Draft status distinguishes Local only, Waiting to sync, Encrypted draft accepted, Partial relay failure, Conflicting remote version, Too large for selected relay. Recovering a NIP-37 draft verifies/decrypts it first and opens it as imported wording; relay history is not HWP capture history. On conflict, Keep Both preserves separate local versions and lets the user select which to continue/publish. Remote deletion is a tombstone/best-effort request; never promise erasure. Users can keep writing while offline without losing access to a fully downloaded file.

**U14 — disciplined-session setup and operation.** Modal preflight selects this document, goal (25-minute default or 500 net added words), strength Focus or Locked, clipboard policy and sound. Show exact restrictions, existing content baseline, emergency exit and bypass limitations before Start. Starting never accepts system permissions via a trap. During a locked session keep editor, progress, Save status and a small Emergency Exit affordance; no publisher/library/other document navigation. Normal focus can be exited immediately; Locked requires goal or a 10-second deliberate emergency exit. The keyboard-accessible exit must work with VoiceOver and without pointer or multiple-key holds. System sleep/lock/switching interruptions pause session progress. Completion quietly offers Continue Writing, +10 Minutes for timer mode, or End Session; no modal celebration. All details follow FOCUS.md.

**U15 — settings/help.** Native Settings sections: Editor, Recording & Privacy, Focus & Sound, Nostr, Export, Advanced Verification. Default policy is the frozen empty production policy; importing an experimental/as-of policy is a separately labelled advanced verification context and never enables global production issuance. Help explains the claim, manual transcription objective, absence of real validation, source-vs-export binding, File Provider behaviour, NIP-44 metadata/key-compromise limits, remote deletion limits, force-quit bypass and how to preserve/verify proofs without the company.

## Keyboard, accessibility and visual acceptance

Use native Cmd-N/O/S/W/P/F/Z/Shift-Z/C/V/X/A and Cmd-comma. Cmd-Return invokes the current mode's publication only outside locked sessions; first-use confirmation still applies. Cmd-Shift-P opens Publish Review (not a command palette). Cmd-Shift-F toggles normal focus; do not overload Ctrl-Cmd-F native fullscreen. Escape dismisses ordinary sheets/find; in Locked it reveals the exit affordance without silently ending the session. Global Quick Post default shortcut is configurable and disabled until opted in.

Every control has an accessibility label, role, logical focus order and keyboard route; states are not conveyed by colour alone. Test VoiceOver from launch through writing/export/publish/focus emergency exit, high contrast, Reduce Motion, increased text sizes, light/dark, narrow window, multiple displays, IME marked text, RTL/bidirectional paragraphs and composed/decomposed accents. Pointer hit targets ≥24pt for toolbar items, larger for the primary actions. Native menus expose all critical actions. Screenshot evidence at 1120×760 and 760×520, light/dark, must show real running Mac UI and the exact commit. Text specifications here are not substitute visual acceptance evidence at Stage 08.
