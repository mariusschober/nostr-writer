# Native deterministic algorithm — independent preparation

This component is isolated on `preparation/native-cores`, based on Stage 01
checkpoint `251a7d1`. Stage 01 and Stage 04 are **NOT ACCEPTED**. The shipping
application candidate is unchanged. No branch has been pushed and no proof or
private writing has been published. All 60 acceptance requirements remain intact.

The native implementation reproduces the frozen joined `hwp0/algorithm` inference
path: exact scalar replay and ancestry, required evidence windows, all 179 fixed-point
features, complete model branch validation, local support, minimum connected motor
episodes, source reuse vetoes, threshold decisions and complete UTF-8 passage scopes.
It uses the already pinned BigInt library for Python-sized arithmetic and explicit
negative floor division. Unicode identities remain exact UTF-8 bytes; Swift's
canonical-equivalence string equality cannot collapse record IDs or source text.
Python-compatible JSON snapshots preserve the algorithm's independent record/model
pin comparisons; canonical CBOR remains the protocol transport.

This is algorithm computation only. Authenticated capture, operational/empirical
release admission, independent policy selection, producer issuance, V verification,
R disclosure reconstruction, CLI verification and proof UI are still mandatory work.
Externally supplied algorithm assumptions default to empty/unapproved. The conditional
positive fixtures supply synthetic laboratory assumptions directly; they are not
production policies, certificates, empirical approval or evidence of a real person
composing text. No fixture authority or force-approve switch is added to the app.

## Differential evidence

The reference fixtures are generated by importing the untouched frozen Python
implementation, after checking its inventory. Generators write only native test
resources. They neither regenerate the frozen vectors nor rewrite manifests.

- 23 complete model validation cases, including unreachable invalid tree branches;
  12 score/support evaluations, including the strict support boundary; and 40
  arbitrary-precision arithmetic/quantile/correlation cases.
- 19 complete replay states, including every atom, observation, effect, ancestry,
  window/membership list, source veto and resource counter; 38 malformed histories
  compared with the frozen first rejection; and 21 scalar/window/spelling probes.
- 9 histories, 304 evidence units and **54,416 individual feature values**, plus
  adequacy decisions. Coverage includes keyboard, touch, IME, gesture, navigation,
  replacement, undo/redo, copying, movement, interruptions, spelling, pasted source,
  source reuse, BOMs and byte-distinct composed/decomposed Unicode identifiers.
- **28 complete assessment outputs**, compared as exact canonical CBOR bytes.
  Cases cover conditional positives, empty independent trust, altered trust pins,
  unsupported domains, release purpose, threshold/claim boundaries, short or empty
  meaningful scope, interruptions, inherited wording and UTF-8 quotation exclusions.
- Four Python JSON snapshot vectors plus invalid-domain/size rejection. Shared test
  blobs and snapshots are deduplicated by SHA-256 and checked on load.
- A cancelled assessment throws `CancellationError`; it cannot return a completed
  scientific negative. Cancellation is also checked during native replay, feature
  extraction, model evaluation, snapshot conversion and scope assembly. Actual UI
  responsiveness and maximum-history performance are not yet measured.

Parent review corrected IME basis ordering to compare global event sequence values,
raw clock ordering across the signed/unsigned integer boundary, and undo/redo
ancestry: touched evidence must use the original roots, never copied or external
occurrence IDs. The complete-state tests exposed that last defect in four histories.
Review also bounded invalid public window parameters and tightened cancellation.
Several intended negative mutations violate multiple invariants; their expected
first errors come directly from the frozen reference, not a hand-assumed label.

The test target alone contains synthetic fixtures; Python is only an oracle-generation
tool, never an application or verifier runtime dependency. The model, feature and
assessment generators in `mac/Packages/WriterHWP/Tools/` accept `--protocol PATH`;
the replay generator accepts `HWP_PROTOCOL_ROOT`. All four otherwise locate
`protocol/v0` from the repository layout. Use a Python environment with the frozen
protocol's dependencies installed.
