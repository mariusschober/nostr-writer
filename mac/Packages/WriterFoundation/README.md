# WriterFoundation

This Swift package implements app-contract helpers and their tests. It was created in Stage 01 from the product contracts because the original package source/tests were not recovered. The historical 47-pass report is not evidence for this implementation; use [Stage 01 evidence](../../../product/mac/evidence/STAGE-01.md) and the later stage ledgers for recorded checks.

Helpers cover exact source-byte revisions and UTF-8/UTF-16 scalar boundaries; revision-bound proof presentation and independent policy; relay URL identity; checked NIP-44 length arithmetic; replaceable-event ordering; voluntary-focus state; and descriptive local observation types.
