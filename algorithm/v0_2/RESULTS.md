## 1. Executed computational checks

The final package runs **76 unittest methods**, with **zero failures, zero errors and zero skipped tests**, using Python 3.13.5, NumPy 2.3.5 and SciPy 1.17.0. The run includes parameterized loops and randomized edit sequences in addition to the method count. It does not count every inner assertion as an independent experiment.

The checks cover exact Unicode replay; scalar/byte boundary validation; parent imports; copy/move/history ancestry; correction inheritance; external-source and correction laundering; repeated input and delayed-cause rejection; overlapping key episodes; IME basis integrity; all four input profiles; malformed clocks/fields/ranges; complete local/global evidence membership; fixed-point feature vectors; missing support/models; both conditional decision branches; quotation scope; learning export and repeatability in this environment; held-out-data exclusion; dependency leakage; ambiguity quarantine; campaign aggregation; missing evaluation cells; exact rational statistical tests; and retention of invalid genuine attempts in accuracy denominators.

One test generates twenty seeded histories of forty random edits each and checks exact replay. Statistical tests compare the integer-tail implementation with direct rational binomial sums for multiple probabilities, sample sizes and failure counts. The learning tests fit the specified four-head tree learner to an artificial numerical dataset and verify nontrivial scores and identical refitting in this environment. That dataset is not human behaviour.

The feature implementation emits **179 precisely named integer features**. The shipped 156-scalar keyboard fixture generates sixteen evidence units under the pinned segmentation. Equivalent synthetic fixtures exist for touchscreen taps, IME commits and gestures.

## 2. Adversarial-mechanics results

The test suite confirms that moving, copying and undoing text do not create new composition roots. Native autorepeat does not become dozens of independent physical actions. A small late insertion cannot pass solely because an unrelated earlier passage has enough evidence. Source reuse and correction derivations retain their necessary provenance and evaluation labels.

The timing attack harness executed eight candidate attempts against the deliberately permissive fixture model and retained them as **one** statistical campaign. This validates attempt accounting, not resilience to adaptive attacks. The fixture has zero-valued decision trees and an intentionally permissive support reference. It is supposed to admit synthetic candidate scores so that the separate release-approval gate is tested rather than hidden behind an always-negative model.

The fixture's complete candidate document score is zero. Its actual public verification result remains **NOT PROVABLE** because no real capture or inference release has been approved. The positive branch is exercised only as a conditional unit test with explicitly supplied laboratory assumptions. No actual HUMAN-WRITTEN credential or real-user certificate was issued.

The observational-equivalence counterexample uses identical observations with different alleged hidden causes and obtains identical features/decisions. It illustrates a mathematical boundary. It is not a measured successful attack on a real trained human-writing detector.

A further label test ensures that a negatively labelled spelling transformation is not silently treated as genuine just because its parent roots have H labels. False-origin evaluation follows contributing transformations as well as the source composition roots.

## 3. Reproducible numerical consequences

For a single fixed test, a zero-failure one-sided 95% upper bound of 0.1% needs **2,995 independent trials**. At that count the computed upper bound is approximately **0.0009997444209011422**.

For the illustrated one-domain release matrix, eight attack families at two budgets produce sixteen required cells. With 32 candidate thresholds and half of the 5% error budget allocated to attack risk, each test uses α=0.025/(16×32)=**0.000048828125**. A zero-failure cell needs **9,923 independent campaigns** to meet the same 0.1% target. This is an evidence requirement calculation—not a claim that those campaigns have been collected.

For truly independent attempts each succeeding with probability 0.001, 1,000 attempts succeed at least once with probability approximately **0.6323045752290363**. The equation is illustrative only; it does not model adaptive white-box optimization. The release matrix evaluates registered campaigns directly instead of extrapolating a random one-attempt rate to unlimited attacks.

Confidence bounds displayed as decimals are computed with SciPy. The release eligibility comparisons use **integer-exact binomial tail arithmetic**, not rounded quantiles.
