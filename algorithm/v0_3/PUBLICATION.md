# Publication status

The consolidated specification, adversarial audit and supporting documentary results were prepared for this repository. The complete HWP-A 0.3.0 reference source, telemetry schema, tests, fixtures and reproducibility scripts were produced locally and passed 100 tests.

The GitHub tool rejected both attempts to upload executable source with: “This tool call was blocked by OpenAI because we couldn't determine the safety status of the request.” No alternate upload route or encoding was used to bypass that block.

Accordingly, the repository publication is documentation and permitted supporting results, not the complete executable source package. The complete package is delivered separately to the repository owner as `HWP-A-0.3.0.zip`. Commands and source-file references in the specification apply to that complete package. This repository subdirectory alone must not be represented as a runnable reference implementation until the source has actually been added and verified.

The historical A1 implementation outside this directory remains unchanged and is not a substitute for the missing 0.3.0 reference source. No empirically approved real-world certification release exists in either version.
